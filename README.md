# Spike-Trace

Spike-Trace 是一个面向排球比赛视频的本地分析软件。长期目标是从比赛视频中识别我方球员的技术动作，按球衣号码归属事件，并形成可持续保存、复核和导出的球员数据。

当前项目处于 MVP 阶段。已确认的首要任务不是先开发完整的数据管理界面，而是先跑通核心动作模型闭环：

1. 输入一段排球比赛视频。
2. 将视频切分为适合模型处理的时间窗口。
3. 识别发球、一传、二传、扣球、拦网等动作。
4. 输出动作类型、起止时间和置信度。
5. 使用真实标注数据训练、评估并迭代模型。

产品架构、数据口径、MVP 边界和开发路线详见 [项目规划](docs/PROJECT_PLAN.md)。该文档也是后续开发者或 AI 接手项目时的主要上下文。
