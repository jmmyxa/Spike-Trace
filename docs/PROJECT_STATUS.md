# Spike-Trace 当前进度与执行计划

更新时间：2026-09-06

本文是项目当前状态的简明入口。它描述已完成内容、尚未完成的验证，以及后续独立会话的任务边界。

## 当前进度

### 已完成

- 动作模型 MVP 已形成闭环：视频读取、固定窗口采样、R3D-18/Tiny3D 训练、整场滑窗推理、动作事件合并、JSON/CSV 导出。
- 动作标签已固定为 `background`、`serve`、`receive`、`set`、`attack`、`block`、`dig`。
- 美国队对德国队已有 90 条人工确认训练窗口，全部属于 `train`；训练集指标不能作为独立准确率。
- Rangitoto 首轮主动学习和证据复核材料已完成，原始复核材料保持不可覆盖。
- 球员身份 MVP 已加入：检测/轨迹/号码/身份分配数据契约、多帧号码聚合，以及仅把已确认美国队身份关联到动作事件。
- SoCal 独立验证工作流已在 `codex/rangitoto-active-learning-round-01` 分支完成并推送，包含视频绑定和 prediction-blind 真值门禁。

### 尚未完成

- 尚未完成 SoCal 的 C2 半场映射、完整回合队列和人工真值锁定。
- 尚未在锁定真值前运行 SoCal 模型识别；因此目前没有可信的独立比赛精度结果。
- 身份 MVP 还没有接入实际人体检测器、跟踪器或 OCR 权重。
- 得分来源、发球成功率、一传等级、上场时间等统计规则尚未接入正式统计引擎。
- SQLite、用户工作区、网页复核界面和正式导出工作流尚未实现。

## 接下来执行顺序

1. 完成 SoCal 侧别映射和 prediction-blind 真值，逐回合确认 C2 动作或明确无动作。
2. 锁定并验证 SoCal 真值后，运行第一个独立 `val` 基线，记录窗口级和事件级指标。
3. 在少量已确认回合上接入球员检测、短期跟踪和人工号码确认，冲突时保持 `Unknown`。
4. 建立事件结果层，区分动作、得分来源、失误、回合结果和遮挡证据。
5. 根据已复核事件计算球员统计，再设计 SQLite 存储和导出契约。
6. 最后实现导入、复核、分析、统计和导出工作台。

## 独立会话任务

### 主控与集成会话

- 维护整体路线、跨模块契约、README 和本状态文档。
- 合并各会话分支，运行回归测试并发布版本。
- 不在主控会话中临时改变动作标签或统计口径。

### 动作模型会话

- 负责标注清单、主动学习、训练、推理、事件合并和模型评估。
- 只输出动作事件与推理证据，不判断球队或球衣号码。
- 当前第一任务：完成 SoCal 真值准备并建立独立基线。

### 球员身份会话

- 负责球员检测、跨帧跟踪、球队判断、号码 OCR 和身份复核。
- 只产生 `IdentityAssignment`；遮挡、背身、冲突和不可读号码必须保留为 `Unknown` 或待复核。
- 不修改原始动作标签、时间窗和动作置信度。

### 统计与数据会话

- 负责得分来源、发球成功率、接发质量、上场时间和遮挡统计的口径与计算。
- 负责 SQLite、版本审计、原始预测/人工确认分层及 CSV/JSON/XLSX 导出。
- 只消费已确认或明确标记状态的事件，不把模型候选直接当成正式统计。

### 前端产品会话

- 负责视频导入、回合复核、真值锁定、分析任务、球员统计和导出页面。
- 通过应用服务/API 使用数据，不直接修改模型文件或 SQLite 表。
- 首版优先做本地浏览器工作台，不先做账号和多人协作。

## 协作规则

- 每个独立会话使用自己的分支或工作树，避免共享工作目录互相覆盖。
- 会话之间只通过版本化 JSON/CSV、类型契约、API 和产物路径交接。
- 任何新模块都要同步更新 `README.md` 和本文件。
- 未经过独立比赛验证的训练集指标，不得写成模型准确率或产品承诺。
- 真值锁定前不得加载 checkpoint、生成预测或使用模型候选辅助人工判断。
